## Why this redirect exists

`CLAUDE.md` was the canonical spec for the original "Synaptic" brand;
on 2026-06 (per the LOGBOOK and `FOOTHPATH.md`) the project rebranded
to "Condura." The file at `condura-mind/MISSION.md` was created
updating the H1 to `# Condura — CLAUDE.md` and is the live canonical
spec going forward. **Two files with the same role** (both called
"CLAUDE.md" inside their content) caused reader confusion, since one
said `# Synaptic — CLAUDE.md` and the other said `# Condura — CLAUDE.md`.

This redirect is the resolution decided 2026-07-06: keep MISSION.md as
the canonical spec; preserve the original CLAUDE.md content as
`CLAUDE.md.legacy`; replace this file with a one-line pointer.

Recorded in `LOGBOOK.md` per the session append.
