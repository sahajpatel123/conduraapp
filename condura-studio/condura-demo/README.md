# Condura Remotion Demo

Remotion films for Condura.

## Commands

```sh
npm run studio
npm run render
npm run still
npm run render:minimal
npm run render:demo
```

## Outputs

- `out/condura-cinematic-launch.mp4` - 27-second, 4:3 social launch film with original Condura command-logic motion.
- `out/condura-cinematic-launch-cover.png` - cinematic launch cover frame.
- `out/condura-minimal-launch.mp4` - restrained, mature launch film.
- `out/condura-minimal-launch-cover.png` - minimal launch cover frame.
- `out/condura-prelaunch.mp4` - high-energy pre-launch teaser.
- `out/condura-prelaunch-cover.png` - pre-launch cover frame.
- `out/condura-demo.mp4` - earlier product walkthrough render, via `npm run render:demo`.

`out/` is ignored so rendered assets do not get committed by accident.

## Cinematic Launch Story Beats

1. Scatter: one request splits across models, files, agents, and browser.
2. Summon: Condura forms as the command layer and receives one instruction.
3. Logic: context routes into planning, approval, and a saved receipt.
4. Launch: Condura, launching soon, `condura.app`.

## Minimal Launch Story Beats

1. The computer can answer, but the work is still scattered.
2. Condura is introduced as a command layer.
3. One request becomes context, route, action, and receipt.
4. Safety and permission stay visible.
5. The product promise lands quietly.
6. Launching soon.

## High-Energy Pre-Launch Story Beats

1. Stop opening another AI app.
2. The command layer arrives.
3. Models, files, browser, voice, and agents collapse into one command.
4. Condura becomes the conductor, not another chat box.
5. Local when possible, cloud when chosen.
6. It asks before touching the machine.
7. Launch CTA.

## Demo Story Beats

1. Problem: one task becomes six open windows.
2. Hotkey: Condura is summoned over the desktop.
3. Routing: the request becomes a visible plan.
4. Demo: voice, screen context, task feed, and approval.
5. Control: autonomy matrix, audit thread, hard stop.
6. Receipt: finished work comes back with proof.
7. Close: Condura CTA.
