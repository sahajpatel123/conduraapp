# condura-thread

> **Thread.** A 60-second kinetic film for Condura — built around a single
> filament that multiplies into a symphony, then converges back into one.
>
> Pure HTML + CSS + JavaScript. No npm. No build step. No framework.

---

## 1. The concept

One thread. Many voices. One conductor.

Condura is the single filament that connects every AI on your computer.
This film *shows* that — starts with one luminous line, multiplies it into
many, weaves them into a constellation of capabilities, types out the
promise letter by letter, builds a column of receipts, and finally resolves
back into a single mark.

It is built for the screen, not for the cinema. It auto-plays but
responds to the viewer — pause, scrub, click, mute, fullscreen. Every
sound is synthesized in the browser. Every particle is generated by code.
Nothing is downloaded except three text files.

## 3. The energy / elegance equation

The two constraints were:

- **Energy** — fast cuts, bold typography, constant motion, particles,
  sound that builds. The viewer should feel a pulse, not read a brochure.
- **Elegance** — a single hue family (deep ink → amber → gold → parchment),
  mathematical compositions, smooth motion, no visual noise.

How they coexist:

| Constraint | Energy lever | Elegance counter-balance |
|---|---|---|
| Fast cuts (2–6s per beat) | Cubic-bezier `0.22, 1, 0.36, 1` eases — fast in, fast out, smooth | No linear motion; every timing function has personality |
| Bold typography | Display sizes up to 320px, -0.06em letter-spacing | Single typeface family, three weights max |
| Constant motion | Particle system + helix rotation + receipt arms | Particles fade in gradually (density ramps with time) |
| Sound build | Harmonic stack C2 → C3 → C4 across 11 beats | Each harmonic is a *single* tone — no chords until the reveal |
| Bright color | Signal amber everywhere — bold | The whole palette is one hue family. Restraint IS the design. |

## 4. The sound leitmotif

Built entirely on **Web Audio API** — no audio files, no assets.

The harmonic build across the film:

```
beat 1  STRIKE       →  C2  (bass drum impact + sustained bass)
beat 2  BLOOM        →  + G2
beat 3  WEAVE        →  + E2, C3  (3 bell tones)
beat 4  MULTIPLY     →  + E3, G3, C4  (rhythmic tick)
beat 5  CONSTELLATE  →  12-tone cluster (one per node label)
beat 6  TYPE         →  percussive + sustained pad
beat 7  RECEIPT      →  low sustained + per-arm clicks
beat 8  SURGE        →  arpeggio climax (C-E-G-C ascending)
beat 9  REVEAL       →  C-E-G-C major chord hit, sustained
beat 10 WORDMARK     →  held warm chord
beat 11 CTA          →  chord resolves and fades
```

The viewer hears the threads *literally* become sound. The chord is built
in front of them.

## 7. Customization

- **Copy:** edit text in `index.html`. Animation timings are independent.
- **Beat timing:** edit the `BEATS` array in `app.js`. Each entry has
  `{ id, start, end }`. `id` must match a `.beat--<id>` class in CSS.
- **Sound:** edit the `SOUND.beatCue(beatId)` switch in `app.js`.
  Primitives: `SOUND.tone(freq, dur, type, vol, when)`,
  `SOUND.kick(vol, when)`, `SOUND.pad(freq, dur, vol, when)`.
- **Palette:** edit `:root` custom properties at the top of `styles.css`.
  Every color in the film is a token.
- **Helix / constellation:** edit `renderHelix()` and `renderConstellation()`
  in `app.js`. The 12-node labels are in `CONSTELLATION_LABELS`.
- **Particle density:** edit the `60` in `initParticles()` or the density
  ramp in `drawParticles()`.

## 8. Output policy

This project is an **interactive experience**, not a render pipeline.
There is no `.mp4`. There is no `npm run build`.

To ship a static video for the marketing site, record the experience
once (browser DevTools > Recorder, or `ffmpeg` + headless Playwright).
Or embed the live version as an `<iframe>` — interactivity is the point.
